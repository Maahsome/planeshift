# Every endpoint below is under the /api/v1/ prefix and uses the
# X-API-Key authentication class through BaseAPIView or BaseViewSet.
# Methods listed here are the application methods; implicit HEAD and OPTIONS
# methods are omitted.
#
# Path parameter conventions:
#   {slug}                 workspace slug
#   {project_id}           project UUID
#   {pk}, {issue_id}, etc. resource UUID unless otherwise noted
#   {project_identifier}   project identifier, e.g. ENG
#   {issue_identifier}     issue identifier, e.g. 123
