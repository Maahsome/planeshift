# Implementation Plan: context prompt

- [x] **🎟️context prompt**
  - **Description:** Implement Jira ticket `PSFT-15-20260917-1111-321544` by adding `planeshift context prompt`. The command is a read-only, shell-friendly projection of the already loaded local context and must write exactly `<workspace> | <project name>` followed by the normal CLI newline. It must read `config.Config.Context.Workspace` and `config.Config.Context.Project.Name`, must not include the project ID or any other configuration, and must not construct a Plane client or invoke an API request.
  - **Scope:**
    - **In scope:** Registering the new child in `@cmd/context/context.go`; implementing the command in a new `@cmd/context/prompt_command.go` so the existing survey adapter in `@cmd/context/prompt.go` remains focused on `context set`; adding safe command help in `@help/context_help.go` and the root context guidance in `@help/root_help.go`; extending unit coverage in `@cmd/context/context_test.go`; adding the command to the help-discovery matrix in `@functional/functional_test.go`; and adding a manual smoke-check item to `@MANUAL_TESTING.md`.
    - **Out of scope:** Changes to the persisted context schema or Viper resolution in `@cmd/root.go`/`@config/context.go`; changes to `context set` or `context get`; use of the standard JSON/YAML/GRON/text/raw output dispatcher; Plane endpoints, client construction, authentication, new aliases, environment variables, third-party dependencies, or a new architecture decision.
