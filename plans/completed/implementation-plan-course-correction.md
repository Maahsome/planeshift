The current `projects` command is nested beneath `get` and all eight project operations are concentrated in `@cmd/get/projects.go`. Move the resource command to a singular top-level `project` command with `projects` as its alias, make the top-level command a dedicated `@cmd/project` package, and put each project operation in its own file. Normalize the existing root version implementation into a command package only as needed to satisfy the top-level-package rule, while preserving `planeshift version` and its JSON default.
