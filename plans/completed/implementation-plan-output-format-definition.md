# Implementation Plan: Output Format Definition

- [ ] **🎟️Output Format Definition**
  - **Description:** Implement the Project output object for Jira ticket PSFT-8 (`PSFT-8-20260914-0727-F001E8`). Project commands that return a resource body—`project list`, `get`, `create`, `create-template`, and `update`—currently route typed API values through the generic `projects.RawOutput`/`objects.RawJSON` path. Add an `objects`-owned Project output type, modeled on `objects.Version`, so every configured output format has an intentional implementation. Preserve the complete JSON representation for JSON, YAML, GRON, and raw output, while making text/table output concise and deterministic with the selected identity fields.
  - **Scope:**
    - **In scope:** Add `@objects/project.go` and focused object tests; wire `@cmd/project/helpers.go` to the new object; remove the obsolete Project-only raw-output bridge in `@projects/output.go`; and extend `@cmd/project/project_test.go` and, where useful, `@config/config_test.go` to verify format dispatch and text rendering. The initial text/table columns are `ID`, `Identifier`, `Name`, `Workspace`, and `Network`; list pages render one row per result and single-project responses render one row.
    - **Out of scope:** Plane routes, request/response contracts, pagination, authentication, error handling, command names/flags, help text, version output, configuration resolution, the shared output dispatcher, `objects.RawJSON` behavior for other resources, new dependencies, generated code, live API calls, and changes to archive/unarchive/delete’s quiet 204 behavior.
  - **Implementation Tasks:**
    - [x] **Govern:** Before changing output ownership, apply the governing sections of `@CONSTITUTION.md`: **Owned Domains** keeps serialization under `objects`, command orchestration under `cmd/project`, and dispatch under `config`; **Coding Conventions** requires the new type to implement `config.Outputtable` structurally and keeps format normalization in `@config/config.go`; and **Forbidden Dependencies & Protected Zones** prohibits new dependencies or generated code. Use ADR-002 in `@ARCHITECTURE.md` and the output contract in `@PLANE_CLIENT.md` to preserve the existing resource-package boundary. This is an application of the recorded output/package rules, not a new architectural decision, so no ADR addition is needed.
      - [x] Create the eventual implementation branch from `main` as `feat/PSFT-8-output-format-definition` and use a conventional commit containing `PSFT-8` (for example, `feat: [PSFT-8] define project output formats`) when implementation is committed; the current planning workspace is on the PSFT-6 branch and should not be repurposed for implementation.
      - *Per user direction, execution continues on the current `feat/PSFT-6-implement-plane-api-projects` branch; no branch switch was performed.*
    - [ ] **Investigate:** Trace all object-returning operations through `@cmd/project/create.go`, `@cmd/project/create_template.go`, `@cmd/project/get.go`, `@cmd/project/list.go`, `@cmd/project/update.go`, and `@cmd/project/helpers.go`. Confirm that the existing typed `@projects/types.go` custom JSON marshaling already preserves nullable, dynamic, and unknown Project/page fields, and that `@objects/version.go`, `@objects/raw_json.go`, and `@config/config.go` establish the method names, error behavior, table conventions, and central dispatch to reuse.
    - [ ] **Implement:** Add `@objects/project.go` with an `objects.Project` output wrapper and a constructor such as `NewProject(value any)`. Marshal the supplied `projects.Project` or `projects.ProjectPage` into a defensive JSON document without importing the route package or duplicating its large schema, then implement `ToJSON`, `ToYAML`, `ToGRON`, `ToRAW`, and `ToTEXT` using the existing approved dependencies and logging style.
      - [ ] **Preserve full structured output:** Delegate JSON/YAML/GRON/raw rendering through the preserved document so unknown keys, explicit nulls, dynamic values such as `icon_prop`/`default_state`, and page metadata remain visible outside text mode. Return constructor/rendering errors consistently with the existing object implementations and never log request credentials or response-sensitive data.
      - [ ] **Define text/table output:** Decode only the summary fields needed for rows, render `ID`, `Identifier`, `Name`, `Workspace`, and `Network` with `tablewriter`, retain result order for list pages, render blank cells for absent nullable values, and honor `noHeaders` exactly as `objects.Version.ToTEXT` does. Avoid dumping arbitrary JSON or long description/dynamic fields in text mode.
