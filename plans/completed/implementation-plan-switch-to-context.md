# Implementation Plan: switch to context

- [x] **🎟️switch to context**
  - **Description:** Implement ticket `PSFT-16-20260917-1322-520771` by replacing the resource-command positional `workspace_slug` and `project_id` inputs with optional named context overrides. Use ASCII `--workspace` and `--project-id` flags; an explicitly supplied flag overrides the corresponding value from `config.Config.Context`, while an omitted flag uses `context.workspace` or `context.project.id` loaded by `@cmd/root.go`. The ticket's `projectd-id` spelling is treated as a typo and normalized to the repository's existing `--project-id` convention. Preserve positional resource identifiers that are not context values, including `state_id`, `work_item_id`, `project_identifier`, and `issue_identifier`, and apply the same behavior to the hidden legacy work-item commands.
  - **Scope:**
    - **In scope:** A pure typed context-override resolver in `@config/context.go`; context flag registration and resolution in `@cmd/project`, `@cmd/state`, and `@cmd/workitem`; all current project, state, primary work-item, and hidden legacy work-item Cobra operations that currently use `workspace_slug` and/or `project_id`; command/package tests; root/context resolution tests; help text and safe examples in `@help/project_help.go`, `@help/state_help.go`, `@help/work_item_help.go`, `@help/root_help.go`, and `@help/context_help.go` as needed; functional help/lifecycle argument updates in `@functional/functional_test.go`; the manual checklist in `@MANUAL_TESTING.md`; and verification using `@LOCAL_BUILD.md` and `@PLANE_CLIENT.md`.
    - **Out of scope:** Changes to the persisted context schema or Viper file format; new Plane endpoints, client methods, route construction, authentication, output formats, or third-party dependencies; changes to `@projects`, `@states`, `@workitems`, `@plane`, or `@spec/plane-api.yaml`; making `project_identifier` implicitly come from the context project UUID; retaining the removed positional grammar as a compatibility alias; or adding context behavior to commands that never accepted a workspace/project route value.
