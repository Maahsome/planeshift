# Implementation Plan: work item activity function test

- [x] **🎟️work item activity function test**
  - **Description:** Add opt-in black-box functional coverage for the newly registered, read-only Plane Work Item Activity commands. The tests must execute the built `planeshift` binary through the existing `@functional/runner_test.go` harness, exercise the real Cobra/configuration/client/output path, and verify both the canonical `activity`/`activities` list and detail operations and the explicitly bounded hidden `/issues/` compatibility operations. Because activities are read-only history, the test will create only a disposable project and work item as prerequisites, observe an activity generated by that work item, and clean up only the generated parent resources.

    - **In scope:** Executable help/command discovery and root-help safety in `@functional/functional_test.go`; a generated project/work-item activity read lifecycle in `@functional/functional_test.go`; opt-in legacy `/issues/` activity list/get coverage using the existing unsupported-route skip helper; an activity ID extractor in `@functional/runner_test.go`; activity-specific functional guidance in `@functional/README.md`; and verification through the existing `@mise.toml` `function-test` task.
