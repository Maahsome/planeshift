# Implementation Plan: work item links

- [x] **🎟️work item links**
  - **Description:** Add the ten explicitly approved Plane Work Item Links operations to the standard client, typed contract, Cobra, output, and deterministic test surfaces. The /work-items/ route family is primary; the matching /issues/ family is retained only as bounded compatibility.
  - **Scope:**
    - **In scope:** A new link resource boundary; typed link, page, create, and presence-aware update contracts; five primary client methods; five explicitly listed compatibility client methods; primary and hidden compatibility Cobra commands; the required root/config/help registration seams; focused OpenAPI and unit/HTTP tests.
    - **Out of scope:** Work Item relation methods already owned by Work 04; comments, activity, attachments, or other link-like resources; inferred /issues/ aliases beyond the five routes in @PUBLIC_API.txt; changes to authentication or transport architecture; generated clients; live credentials or functional lifecycle tests; new third-party dependencies; unrelated route or package refactors.
