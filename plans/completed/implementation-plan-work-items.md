# Implementation Plan: work-items

- [x] **🎟️work-items**
  - **Description:** Implement Jira ticket PSFT-13 as the complete Work Items slice for `planeshift`. The slice contains exactly 16 application methods: nine current `/work-items/` methods (core CRUD, search, identifier lookup, and relations) and seven explicitly inventoried deprecated `/issues/` core aliases. Current routes remain the preferred API family; compatibility aliases are opt-in and bounded by `@PUBLIC_API.txt`.
  - **Scope:**
    - **In scope:** The new `@workitems` route-specific client and typed contracts; the resource-oriented `@cmd/workitem` Cobra hierarchy; command registration in `@cmd/root.go`; command names in `@config/aliases.go`; safe Work Item help in `@help`; the Work Items portions of `@spec/plane-api.yaml`; focused model, client, command, and root tests; and narrowly reusable test support in `@internal/testsupport/http.go` only if an existing assertion is insufficient.
    - **Out of scope:** Links, comments, activity, attachments, their compatibility families, states, labels, cycles, modules, intake, project changes, a second transport or configuration path, new dependencies, generated/OpenAPI code, live Plane calls, undocumented advanced search or relation-removal routes, and any `/issues/` route not listed in `@PUBLIC_API.txt`.
