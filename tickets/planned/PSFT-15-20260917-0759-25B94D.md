# Work Ticket

ID: PSFT-15-20260917-0759-25B94D
Title: add context

## Description
I would like to add a "context" top level command, with "set" and "get" as sub-commands.

These commands will be responsible for setting the following properties in the config file:

```yaml
context:
  workspace: maahsome
  project:
    id: 69dcd75e-b24b-4cb2-aa63-08db83cf1ced
    name: planeshift
```

The commands will be:

`planeshift context set`

`planeshift context set —workspace <workspace slug>`

`planeshift context set —project <project id>`

`planeshift context set —workspace <workspace slug> —project <project id>`

`planeshift context get`

When the "context set" is run without parameters, I would like to use go package `github.com/AlecAivazis/survey/v2` to prompt to provide the workspace and then the project, prompting to select the project by name, and returning the project name and id to be updated in the config file.

The "context get" should provide the standard output options.
